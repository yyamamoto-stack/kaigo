# 日次 実績未記載チェック

## 目的

Google Drive に毎日追加されるシフト表PDF（予定・実績）を照合し、実績記録が無い訪問をリスト化し、従業員向け周知文を作成する。

## 対象フォルダ（Google Drive）

| フォルダ | ID |
|---|---|
| 受信フォルダ（PDFが毎日追加される） | `1MvOczr46gSNGlRiWamc9oMrNATzdfl-K` |
| 実績未記載チェック（整理用の親フォルダ） | `1H2AVbbykp7vfyAlAE_A7x-BGco8QhP4C` |
| └ PDF（予定・実績） | `1iG36uaLgyd_d-waOxXOsrQBS9M0p0bcM` |
| └ スプレッドシート（実績未記載リストの出力先） | `11jvvzXGm4zRjApzeV4MikETdtugqHOry` |
| └ メッセージ下書き（周知文txtの出力先） | `1TVfj33EcM0xcAfJeDwTyPOUzweM_MqGG` |
| 不要物（ユーザーが手動で移動するゴミ置き場） | `10kSgHyBOCDW7hqAonzZGMxqAuR6b4HVN` |

マスターデータ: リポジトリの `data/実績未記載リスト.csv`（Driveのシートはここから再生成する）。

## 手順

1. **新着PDFの特定**: `mcp__Google_Drive__search_files` で受信フォルダ直下のPDFを列挙する
   （query: `parentId = '1MvOczr46gSNGlRiWamc9oMrNATzdfl-K' and mimeType = 'application/pdf'`）。
   `data/実績未記載リスト.csv` に既に行がある日付は処理済み。未処理の日付のPDFだけを対象にする。
   予定/実績の区別はPDF本文の「シフト表(予定)」「シフト表(実績)」、対象日は本文の日付（例: 令和8年7月12日 → 2026/07/12）で判定する。
2. **照合**: `mcp__Google_Drive__read_file_content` で予定・実績の両PDFを読み、「サービス提供時間 × ご利用者名」の組で突き合わせる。
3. **実績未記載の判定**: 予定にあって実績に対応する行が無いものを「実績未記載」とする。ただし:
   - 予定の備考に「キャンセル」「入院」「帰国」「帰省」など訪問中止を意味する語がある行は**リストに載せない**（対象外として件数だけ記録）。
   - 2人対応の行（備考「2人目」等、ヘルパー名が空欄の行）は、実績側に対応する行があれば記載ありとみなす。
4. **CSV更新**: `data/実績未記載リスト.csv` のヘッダー直下に新しい日付の行を挿入する（**日付降順＝新しい日付が上**を維持）。
   - 列: `日付,サービス提供時間,ヘルパー名,ご利用者名,サービス内容,予定の備考,状態`
   - 未記載がある日: 1件につき1行、状態は「実績未記載」。
   - 未記載ゼロの日も監査用に1行追加: 状態に「実績未記載なし（予定n件：実績ありn件／対象外n件＝氏名（理由）…）」と記載。
5. **Driveへシート出力**: CSV全文を `mcp__Google_Drive__create_file`
   （contentMimeType: `text/csv`、タイトル: `実績未記載リスト`、parentId: スプレッドシートフォルダ）で
   Googleスプレッドシートとして作成する。
   - **注意**: Driveツールには更新・削除・リネーム・移動が無いため、シートは毎回「作り直し」になり前日分が残る。完了報告で、古い「実績未記載リスト」を「不要物」フォルダへ移動するようユーザーに一言添えること。最新版は modifiedTime が最も新しいもの。
6. **周知文の新規作成**: 「メッセージ下書き」フォルダに `YYYY-MM-DD_周知文.txt` を作成する
   （contentMimeType: `text/plain`、`disableConversionToGoogleType: true`）。
   - 簡潔に。日本語の文章の下に、同じ内容の中国語（簡体字）を続けて1枚のテキストにする。
   - 未記載がある場合: 対象のヘルパー名・時間帯・ご利用者名を列挙し、速やかな実績入力を依頼する。
   - 未記載ゼロの場合: 未記載なしの報告と、当日中の実績入力継続の依頼。
7. **PDFの整理**: 処理した予定・実績PDFを `mcp__Google_Drive__copy_file` で「PDF（予定・実績）」フォルダへ
   `YYYY-MM-DD_シフト表（予定）.pdf` / `YYYY-MM-DD_シフト表（実績）.pdf` の名前でコピーする。
   - 元PDF（MEM…pdf 等）は受信フォルダに残る（移動・削除は不可）。完了報告で「不要物」への移動を案内する。
8. **コミット & プッシュ**: CSVの変更をコミットし、`claude/daily-performance-analysis-wgob7a` ブランチへ push する。
9. **完了報告**: 対象日 / 未記載の件数と内訳（または「なし」）/ 作成したシート・テキスト・PDFコピーのリンク / ユーザーに依頼する手動整理（古いシート・元PDFの「不要物」行き）を簡潔にまとめる。

## 実行スケジュール

Claude Code Remote のトリガー（Routine）「日次実績未記載チェック」が毎日 02:00 UTC（日本時間 11:00）にこのセッションを起こして本スキルを実行する。
PDFがまだ届いていない（新着なし）の場合は、その旨だけ報告して終了する。
